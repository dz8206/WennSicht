      三、智能功能（会调用大模型）

      默认使用官方公益中转，不需要您做任何配置。

      设置：智能功能的用途与开关

      开启后，扩展会按页面场景自动提供：场景解析播报（这是什么页面、操作难度）、图片描述、 页面结构摘要、模糊链接意图补充（给「点击这里」类链接补一句去向说明）、 图表描述（画布图表由视觉模型说明类型、坐标轴与趋势，标注「AI推测」）。 纯装饰图片不消耗调用次数；常见功能图标（购物车、搜索、关闭等）用本地词典识别，不发给模型。


      供使用鼠标的低视力用户重听描述。

      设置：大模型接口（公益中转 / 自己的接口）

      默认使用官方公益中转：无需注册平台、无需充值、无需配置密钥， 开箱即用（有每日公益额度限制）。高级用户也可切换为自己的接口 （自带 API 密钥）。密钥不会明文保存，也不会再次显示。

      接口来源

      正在读取公益中转状态…

      前置档 primary（可选）优先承担请求，扩展按每秒 1 次节流； 图片描述限速溢出的请求自动交给默认档，整体吞吐不低于每秒 2 张。 整块留空则只使用默认档；只填部分模型也可以（例如只填文本模型）， 没填的那一类（文本 / 视觉）自动改用默认档的模型。 一旦填了任何一项，接口地址与密钥都必须补齐。 默认档 default（必填）是智能功能的基线，并承担全部决策模型调用； 接口地址、文本模型、视觉模型、决策模型四项都必填，缺任一项智能功能不可用。 两档各自使用独立的 API 密钥。接口地址填到 /v1 为止。

      默认档 default（必填 · 智能功能基线 · 承担决策模型调用）





      决策模型：对页面回答类型化问题（页面类型/操作难度/是否需要增强）， 返回概率而非文本。填错或留空会让场景解析、链接意图等判定失效（其余功能不受影响）。


      设置：密钥金库主密码（仅「使用自己的接口」时需要）

      使用官方公益中转时无需配置密钥，本节可忽略；以下仅在您改用「自己的接口」时需要。 API 密钥用浏览器内置加密（AES-GCM）存盘，由您的主密码保护：主密码不会存储、 不会上传，忘记后只能重新填写密钥。每次重新打开浏览器后第一张图片描述前 需要先在这里解锁一次（或重新输入主密码），之后本浏览器会话内不再询问。


      忘记主密码无法找回密钥，请记在您可靠的地方。


      设置：敏感站点保护

      政务、医疗、金融类网站默认完全不处理：页面不做任何修改，内容也不外发，判定全部在本机完成。 你自己开启过的这类网站（开启过它、或按过快捷键）会直接正常运行——和普通网站一样， 不再提示这类网站的隐私限制，并出现在下面的列表里。 「全局启用」时遇到这类网站默认关闭：要开启就连按两次 Ctrl+Shift+Z

      银行、支付类网站与浏览器内部页面（chrome:// 等）扩展完全不处理，开了「全局启用」也一样。

        四、浏览体验

        设置：播报增强做了什么

        开启后，开启增强时会说明「修复了 3 个标题、隐藏 2 个噪音块」这类结果，图片描述也会报进度。 关掉后只说「无障碍增强已开启」，不再逐项报告改了哪些内容； 图片无法加载、验证码这类需要你知道的提示仍然会播。

        设置：记住并恢复上次浏览位置

        开启后，您网页读到一半离开，或者刷新以后，能够自动回到离开时的位置，并报出所在小节的标题。

        设置：动态变化播报

        开启后，页面上新增或移除大段内容时会播报一句「页面有更新：新增 2 段内容」。 适合秒杀、抢购、聊天等会自动刷新的页面，多数静态页面不需要。


        已开启播报的网站

          还没有为任何网站开启。

          五、隐私与数据（说明，无需设置）

          本扩展不收集、不上传任何浏览数据，所有设置仅保存在本地浏览器中。 智能功能会将网页内容发送到AI服务器，其中不会包含您的任何个人信息或者输入内容。敏感站点的智能功能默认关闭。
