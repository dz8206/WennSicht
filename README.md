# 循光WennSicht

面向中文网页的屏幕阅读器增强扩展（兼容Chromium浏览器，主要适配 NVDA）。

开启后，扩展在当前页面注入一层可逆的无障碍增强；再按一次快捷键，所有修改按日志逆序撤销，页面恢复原状。

## 页面结构

- **标题**：把视觉标题补成 `h1–h6` / `role=heading`，修正 `aria-level`；不覆盖网站已有语义。
- **地标**：为 `main` / `nav` / `header` / `footer` / `aside` 等区域补 `role` 与名称；重复导航只保留一份。
- **噪音**：隐藏重复导航、空语义容器、广告与推广浮层；不隐藏含可交互元素的区域。
- **交互语义**：给有 `cursor:pointer` 或内联 `onclick`、且没有原生角色的 `div` / `span` 补 `role=button` + `tabindex=0`；Enter / Space 转发为 click；没有名字的图标按钮按 ARIA 状态、同容器结构、类名关键词、兜底「未命名」依次命名。
- **表格**：缺表头时补列头与行列数说明。
- **链接**：为「点击这里」「了解更多」这类链接补去向说明。
- **表单**：焦点落在无标签输入框时播报本地推断与必填/长度提示；报错字段即时播报；不修改任何表单元素或值。
- **图表**：提取 SVG 内的文字标签；canvas 图表可选模型描述。

## 图片

- 识别缺失 alt、文件名式垃圾 alt；按尺寸与交互上下文分为装饰图 / 图标 / 内容图。
- 装饰图设空 alt；图标先查本地词典；内容图调用可选视觉模型，结果以「AI描述：」开头。
- 验证码只标「验证码图片」并提示语音验证码等替代入口，不描述内容。
- 轮播与替换式图片：监听 `src` / `srcset` 变化，撤销上一张的旧描述，按新图重新生成；回包晚于换图时仍写入描述缓存，轮播转回时立即注入，避免旧描述继续对应当前图片。
- 描述按来源缓存（跨刷新），避免重复调用；易变图有单独的重描述上限。

## 页面理解与问答

- 以标题为界切块，收集可见文本、表格与标题大纲；支持按块或页面小节引用做本地直答。
- 先判断能否只凭当前焦点材料回答；不能则进入整页模式：短页给全文，长页做关键词检索并扩展邻块。
- 回答要求注明来源块；材料不足时返回无相关信息，并有本地摘句兜底。
- 位置判定优先读 NVDA 组件的浏览光标；没有组件时用 DOM 选区、滚动轨迹与视口阅读线；没有确定信号时标注为估计并给出附近候选。
- 位置判定会剔除扩展自身 UI 的文本（问答弹窗、答案、播报区），避免把自己的答案当成页面位置。

## 读屏与动态内容

- 可选的 NVDA 本地组件：本机回环通信，读取当前浏览行并定位当前节，可非侵入式优化三项 NVDA 设置；不安装不影响其他功能。
- 动态内容：监听路由变化与 DOM 新增内容；按站点开启后播报新增内容块。
- 所有播报走单一 `polite` live region，错误与恢复有明确文案。

## 可逆与安全

- 所有 DOM 修改记入 journal，关闭增强时逆序撤销；刷新后不残留。
- 不自动点击、不自动提交、不自动填写，不读取用户输入值，不拦截网络请求，不收集浏览历史。
- 银行、支付、医疗、金融、政务等敏感站点默认不处理，除非用户明确开启。

## 权限

- `activeTab`：仅本页启用时按用户手势注入一次。
- `scripting`：动态注册/注销内容脚本，以及按需注入。
- `storage`：保存设置、站点列表、描述缓存与加密后的密钥。
- `downloads`：下载可选的 NVDA 组件。
- 主机权限：`http://127.0.0.1/*`（本地 NVDA 组件）与 `https://api.wennlicht.us.ci/*`（可选 AI 与反馈）；`<all_urls>` 仅在用户添加站点或开启全局启用时申请。

## 使用

- 在 Chrome 应用商店安装（商店页地址随发布更新）。
- 首次安装自动打开引导页，逐项配置。
- `Ctrl+Shift+Z` 开启/关闭；`Ctrl+Shift+S` 页面摘要；`Ctrl+Shift+U` 反馈；页面问答、布局地图、图片长描述的快捷键可在 Chrome 扩展快捷键页设置。
- 详细操作见扩展内引导页与设置页。

## 隐私

- 基础修复全部在本地完成。
- AI 功能可选；开启后只发送图片字节与页面短文本片段，不含网址、Cookie、表单值。
- 无遥测、无远程代码；反馈只在用户点击发送时离开本机。
- 隐私政策：<https://api.wennlicht.us.ci/privacy-policy.html>
